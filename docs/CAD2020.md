# KCAD 安装与验证

## 安装

1. 从 [KCAD 公开下载页](https://github.com/mouwuyunni/KCAD/releases/tag/latest) 下载 `RuiCAD-CAD2020.zip`，完整解压到本地。
2. 关闭 AutoCAD，双击 `install.bat`。脚本把 `RuiCAD.bundle` 安装到当前用户的 `%APPDATA%\Autodesk\ApplicationPlugins`，并在已有的 CAD 用户配置中登记该包的受信任路径。
3. 打开 AutoCAD 2020 x64，并新建或打开一张图纸。左侧会显示 KCAD 工具面板。关闭面板后，输入 `KCAD` 并回车可再次打开。
4. 要卸载，关闭 AutoCAD，双击同目录的 `uninstall.bat`。如果已有自建 DWG 图库，脚本会在用户 Autodesk 目录下备份图库。

插件使用 AutoCAD 2020 的 .NET Framework 环境，安装端无需下载 SDK 或编译工具。AutoLISP 内容按简体中文 Windows 的系统代码页 936 打包。清单允许 AutoCAD 2019–2024 尝试自动加载，交付目标为 AutoCAD 2020 x64。

## 试画

- 在空白图纸中，用 `11` 两点画一个 900 × 2400 的柜体框架。用 `3` 点击内框，输入 3 和板厚 18。应得到四个等净高的开口。
- 在独立闭合外框内，用 `1` 点选生成内框。用 `2` 点选空腔并输入距底或距顶的距离。支持框选的命令可输入 `Box` 键入两角点。
- 点击面板里的 `6`，在绘图区点选空腔并生成两扇门。用 `MF` 验证开启标记和拉手翻转，用 `MBFX` 验证已有矩形门板四周缩缝或分缝。
- 用 `44` 验证固定高度抽屉的向上和向下排布。用 `66`、`8`、`BY`、`9` 检查玻璃框、回字框或百叶、半圆顶、移门搭接和轨道。
- 用 `BB` 加背板，再画两条分别穿过板件的横纵剖切线，检查 `PP` 生成的剖面。剖面按开口立面中的 RC 图层轮廓和给定柜深绘制，旧版散线按邻近线距离推断成板。
- 用 `RCML` 切换门板图层可见性，用 `RCL` 切换当前图层。按 `RC` 修改参数后，用 `11` 或 `6` 检查新默认值。
- 将一个 DWG 文件放入已安装包的 `Contents\library\`，用 `KLIB` 在命令行选编号并指定插入点。

点选识别要求闭合矩形位于当前 UCS 平面、轮廓完整显示，且空腔内没有孤岛。用 `PM` 绘制单扇门板侧剖。用 `PP` 识别的背板需用 `BB` 或放在 `RC-背板` 图层的闭合轮廓，旧 `BQ` 与其他内部散线共用图层。

## 从源码构建

在仓库目录运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`。需要 MSBuild 或可运行 MSBuild 的 .NET SDK。脚本通过 NuGet 恢复 23.1.0 引用，构建目标为 .NET Framework 4.7.2 x64，并生成 `dist\RuiCAD-CAD2020.zip`。GitHub Actions 在 `main` 或 `v*` 版本标签推送时构建，同时上传 Artifact 和公开 Release。

在装有 AutoCAD 的开发机上，运行 `powershell -ExecutionPolicy Bypass -File .\test\run-tests.ps1`，可用 Core Console 复跑原有 47 项用例。脚本构建旧版 CAD 可读的测试副本，输出日志到 `dist\`。
